Программа выведет числа от 1 до 8 в случайном порядке. Он зависит от случайных задержек при записи в каналы
Функция asChan() создает канала и вызывает горутину, которая будет последовательно записывать переданные числа(vs), ждать от 0 до 1 секунды, а после записи всех чисел в канал будет его закрывать
Функция merge() объединяет 2 канала в 1: создает канал и вызывает горутину, которая будет читать данные из 2 переданных каналов с помощью select: он будет ждать когда в одном из каналов появятся данные для чтения и выполнять соответствующий кейс, а пока этого не случилось - блокируется. Если в обоих каналах есть данные, то он выберет случайный из них. Если канал закрыт, то при чтении он вернет 0, false и канал станет равен nil. Это нужно для того чтобы select не проверял пустой канал бесконечно. После того как все данные из 2х каналов записаны в канал c, он закрывается и происходит возврат из функции.
В main() мы создаем 2 канала чисел с помощью asChan(), объединяем их с помощью merge() и выводим значения из объединенного канала.
